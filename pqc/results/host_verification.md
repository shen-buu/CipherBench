## 二·补：nn_len 宏均的逐类分解（碰撞位点澄清，2025-09-17 核对）

两处长度碰撞是**不同的位点**，16B 之差不是矛盾：
- **768B 三向碰撞（人为设计，类表所述）**：aes256gcm_ct_768 × mlkem512_ct × urandom_768（同长对照）。
  1-NN 并列取首索引 → 逐类 F1 = **0.5000 / 0.0000 / 0.0000**（合计 0.5 个类）；
- **784B 近碰撞（自然涌现）**：aes256gcm_ct_784（300/300 件 784B）× rsa2048_cert（**仅 3/300 件 784B**，297 件 785B，
  实为 784-785 区间）。逐类 F1 = **0.995025 / 0.994975**（合计 1.99 个类，损耗 0.01）。

恒等式核对（逐位）：
- 实测 0.926176 = (29×1 + 0.5 + 0 + 0 + 0.995025 + 0.994975) / 34 ✓
- 朴素恒等式 0.926471 ≈ 0.9265 = (29×1 + 0.5 + 2×1) / 34 —— 768 三向已按 0.5 计，784 组被误当全对；
- 差 = 0.000294 ≈ 3×10⁻⁴，**全部来自 784B 近碰撞**。原注释方向正确，现补全分解以免误读。

## 三、裸原语 0.0744 的机制闭合（E2 置换零带 + 逐类定位）

- 置换零带（10 置换）：0.0630±0.0042，范围 [0.0537, 0.0688]；实测 0.0744（z=2.7）；
- 逐类定位：**ecdsa_p256_sig = 0.2508**（DER 标签 0x30/0x02 + r/s 前导零的结构指纹）；其余 15 类均值 **0.0626 = 零带中心 0.0630**；
- 论文表述：裸原语层在 P1 下≈随机，唯一例外 ECDSA（DER 编码结构被微弱捕获，F1=0.251）——这恰是方法灵敏度的正面证据（连 DER 标签都抓得到，而所有均匀格式类都在零带内）。

## 三·补：高 F1 类的机制说明（一眼错终检）

- rsa2048_pkcs8 在 P1 下 0.998：对象 1188-1193B，1024B 随机窗命中头部概率 ≈86%，头部 DER 长度字段泄漏身份——真实结构指纹；
- crt 组短证书（ecdsa 388B / ed25519 323B / rsa 784B）≈0.999-1.000：整个 DER 入窗；
- mldsa65_pkcs8（4098B）P2=1.000：头部 OID+私钥 η 结构直通；
- 长证书（mldsa65_cert 5513B）P1 仅 0.178：随机窗罕见命中头部。

## 三·补2：ECDSA 机制的填充后门排除（正面对照）

- 假设：短对象+随机填充 → 填充占比 = 长度代理（B4 零填充后门 0.988 的变体）；
- 排除 1：最短类 Ed25519（64B）0.0713 与均匀类同列，ECDSA（70B）0.2508——若填充占比是机制，最短类应最亮；
- 排除 2：长度↔F1 r = −0.186，无梯度，单点 spike；
- 排除 3（构造）：P1 填充为均匀随机字节，与均匀内容统计不可区分——构造上无此信道；
- 结论：ECDSA = DER 标签内容结构。写入论文 Discussion。

### BiLSTM 近随机的机制闭合（准则 0 双对照）

- 现象：BiLSTM P1/P2 均≈chance（0.023/0.037），cert-p2 冒烟诊断（7 类，chance=0.143）仅 0.036-0.072；
- **对照 1（接线自检）**：全 0x00 vs 全 0xFF 恒定序列 → loss 0.695→0.671，train acc **1.0** → 网络可学习、接线无缺陷；
- **对照 2（梯度消失）**：信号在前 4 字节 + 1020 随机噪声字节 → loss 恒 ln2（0.693）→ 最后一步输出的梯度穿不过 1020 步噪声；
- 结论：字节级 LSTM 对"嵌入随机噪声序列的稀疏/头部信号"存在梯度消失，是**诚实架构结果**而非 bug；
  与 CNN（7 字节卷积核任意位置拾取局部字节模式）形成敏感度对照：字节信道残余信号依赖归纳偏置。
- 论文表述：混合 34 类下 CNN 0.21/0.34 而 BiLSTM ≈ 随机 —— 字节层信号脆弱性（模型归纳偏置敏感）的直接证据。

## 四·补2：C2 校准 + 灵敏度梯子（波次3 CNN/BiLSTM，案例 #22，2025-09-17）

设计：5 合成类 × 300 × 1024B（数据集种子 20250917，E4 均衡）；类信号 = 8B 类令牌注入 128 个
8B 槽位，槽位以概率 λ 携带令牌、其余均匀随机字节；λ∈{0,0.0625,0.125,0.25,0.5,1.0} 六梯级；
P1 协议、raw 字节、batch 128、15 epochs、5 折 × 5 seeds（与正式流水线完全一致）。

**窄频带令牌（0xA0/0xA8/0xB0/0xB8/0xC0，8B 重复）：**

|---|---|---|---|
| 0.0 | 0.091±0.020 | 0.111±0.026 | 0.2 |
| 0.0625 | 0.097±0.039 | 0.109±0.025 | 0.2 |
| 0.125 | 0.152±0.063 | 0.134±0.022 | 0.2 |
| 0.25 | 0.360±0.108 | 0.155±0.030 | 0.2 |
| 0.5 | **0.893±0.024** | 0.196±0.022 | 0.2 |
| 1.0 | **1.000±0.000** | 0.187±0.105 | 0.2 |

**宽频带令牌（0x00/0x40/0x80/0xC0/0xFF）：** CNN 1.000±0.000；**BiLSTM 0.893±0.131（3/5 seeds=1.000）**。

**真实数据正控制（cert-p2，7 类，chance 0.143，RF 锚点 0.8488）：**
CNN **0.534±0.147**（seed 值 0.28-0.72，1/5 坍缩）；BiLSTM **0.065±0.013**（低于 chance，与梯子一致）。

**C2 判定（E3 要求：≥0.60 或报灵敏度梯子）：**
- CNN：λ=0.5/1.0 = 0.893/1.000 → **校准通过**；灵敏度曲线 0.09→1.00 单调爬升；
- BiLSTM：宽频带 λ=1.0 = 0.893 → **校准通过**；窄频带全梯级 ≤chance → 标量窄动态输入编码弱点
  （同一 15-epoch 协议对宽动态信号可学到 1.0，排除"训崩"）——与既有梯度消失对照共同解释正式 chance 级结果；
- 真实数据：CNN 0.534（3.7× chance，高种子方差=15-epoch 预算在 2100 样本组级上的边际性，混合 34 类 10200 样本不受影响）；
  BiLSTM 0.065 为诚实记录；
- 结论：正式格 BiLSTM≈随机、CNN<RF 不是实现事故——同一管线在合成信号上分别达到 0.893/1.000，
  差异由"信号浓度×编码方式"的灵敏度梯子定位（λ=0.5 时 CNN 0.89 vs BiLSTM 0.20 即为敏感度梯子图数据）。
