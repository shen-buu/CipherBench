# 波次3 收尾实验记录：C_align 对齐信道 + 乱序/多窗口鲁棒性

脚本：`exp_align_order.py`（v3.0）｜数据：`data/`（34 类 × 300，gen_formal_v1.0，SEED 20250912）
规范：E8 每 seed 独立窗口 RNG；E14 均值 ± seed-std（3 seeds：42/123/2024）；5 折分层 CV；
禁零填充；P1 短对象随机位置 + 均匀随机填充；P2 头部锚定 + 随机填充；
特征器与正式 rf/hgb 基线一致（`statistical.extract_full_features`，170 维）。

## Part 1 C_align（全部 34 类 × 10200 对象，1-NN，与 len 信道同法）

| 配置 | F1 (mean ± seed-std) | 解读 |
|---|---|---|
| A1 精确对齐 (⌈L/B⌉, L mod B)，B=512/1024/4096 | 0.9262（三者相同） | (⌈L/B⌉, L mod B) 是 L 的双射；与冻结 nn_len 0.9262 **逐位吻合** → 管线自检通过，精确对齐观测等价于长度信道 |
| A1 仅块数，B=512/1024/4096 | 0.3686 / 0.1922 / 0.0979 | 粗粒度长度，信息随 B 增大而衰减 |
| A1 仅尾块填充，B=512/1024/4096 | 0.8154 / 0.8870 / 0.9262 | 残差分量承载主体信息；B=4096 时残差对所有类仍为双射（最长对象 29792B，无类间模碰撞） |
| A2 移位对齐 (3 特征，off~U(0,B))，B=512/1024/4096 | 0.8748 / 0.8694 / 0.8330 | 随机起始偏移只造成温和退化（0.9262 → 0.83–0.87），原因：首块填充+尾块填充之和对 B 取模恒等于 L mod B（ff+fl ≡ L mod B），观测者可从两填充的**同余关系**恢复长度残差 |
| A2_nt 仅 (块数, 尾块填充)，B=512/1024/4096 | 0.3765 / 0.2377 / 0.0904 | 丢失首块填充后同余密钥丢失：fl 单独对 L 均匀（无信息），仅剩块数的一枚"偏币"位 → 信道崩溃至近随机（chance=1/34=0.029）|

**结论（修正框架"预期最先死于噪声"的悲观猜测）**：C_align 不死于对齐噪声本身，而死于
**首块填充不可观测**。它与 C_struct 共享同一个死穴：头部依赖。

## Part 2 乱序鲁棒性（pkcs8 11 类 × 3300 / cert 7 类 × 2100，分组建模）

窗口：每对象每 seed 5 个 P1 随机窗口 + 1 个 P2 头窗（同一 per-seed RNG，E8）；
特征：170 维 stats（同正式 rf 基线特征器）；分类器：rf300 主报（同冻结配置），1-NN/rf100 作敏感性检查；
5 折分层 CV × 5 seeds（7/42/99/123/2024），± = seed std（B 网格全格统一）。

**B0-B3 语义（轴方向声明，防止"噪声越大越准"误读）**：四个配置不是"乱序强度"单调轴。
乱序在本实验中是**二分状态**（碎片顺序可辨识 vs 不可辨识），且与两个正交因子共同作用：
**窗口数（1 vs 5）**与**头部可辨识性（无头 / 头在场不可辨识 / 头可辨识）**。B1/B2 均为
顺序不可辨识的无序袋；B0/B3 为单窗（顺序维度退化）。因此数值随 B 编号上升**不是**"噪声增强
反而更准"，而是"窗口数 1→5 的平均降方差增益"与"头部可辨识性"两个因子在起作用。

| 头窗状态 \ 窗口数 | 1 窗（顺序维度退化） | 5 窗乱序袋（顺序不可辨识） |
|---|---|---|
| 无头 | B0：pk8 **0.5381±0.0050** / crt **0.6017±0.0066** | B1：pk8 0.7686±0.0053 / crt 0.6880±0.0101 |
| 头在场、不可辨识 | — | B2：pk8 0.7895±0.0048 / crt 0.7781±0.0050 |
| 头在场、可辨识（P2 协议） | B3：pk8 0.6931±0.0069 / crt **0.8488±0.0026** | B5：pk8 0.8378±0.0015 / crt 0.8331±0.0022（X=[f(h)‖mean(f(w0..w4))]，340 维） |

配对对比（同窗口数内才可比）：
- 多窗口增益（无头，1→5 窗）：B1−B0 = **+0.2305 (pk8) / +0.0863 (crt)**；
- 头部可辨识增益（1 窗域）：B3−B0 = 0.1550 (pk8) / 0.2471 (crt)；
- 头部可辨识增益（5 窗袋域）：B5−B1 = 0.0692 (pk8) / 0.1451 (crt)——比 1 窗域小，
  因袋平均本身把头部特征摊薄（4 个随机窗稀释）；
- 头部不可辨识增益（5 窗袋）：B2−B1 = +0.0209 (pk8) / +0.0901 (crt)；
- **乱序保留率（同域公式）= (B2−B1)/(B5−B1) = 30.2% (pk8) / 62.1% (crt)**——
  头窗在场但不可辨识时，其袋内增益仅剩同域可辨识时的 30.2%/62.1%。
  （原跨域公式 (B2−B1)/(B3−B0) = 13.5%/36.0% **作废**：分子在 5 窗域、分母在 1 窗域，不可比；
  若与 1 窗域头部增益比较，乱序的折扣更大——两域合并看：头部增益 0.16/0.25（1 窗可辨识）
  → 0.07/0.15（5 窗袋可辨识，摊薄）→ 0.02/0.09（5 窗袋不可辨识，乱序））。

**锚点复现自检（准则 0）**：
- 本地跑冻结流水线 `train_baselines.py --arch rf --scene p1 --groups pkcs8` 5 seeds =
  0.5621/0.5527/0.5403/0.5559/0.5485，与宿主 55 文件逐一吻合（同一多重集）→ 均值 0.5519 复现；
- B3 ≈ 冻结 P2（5 seeds 对齐后）：pk8 0.6931 vs 0.6953（Δ=−0.0022），crt 0.8488 vs 0.8488（Δ=0.0000）；
- B0 ≈ 冻结 P1（5 seeds 对齐后）：crt 0.6017 vs 0.6031（Δ=−0.0014）；pk8 0.5381 vs 0.5519（Δ=−0.0138，
  同 seeds 同协议、唯 RNG 流不同〔每对象 5 窗〕→ 同协议再实现的抽样噪声，
  已由 5-seed 逐种子复现排除系统性差异）。

**结论（表 5 支撑）**：
1. 乱序不杀 C_bytes：无序袋反而增益（多窗口平均降方差）；pk8 的无序袋 0.767 甚至
   超过单头窗 0.696（pkcs8 判别结构分布在全对象，头部仅共享 ASN.1 头）。
2. 乱序折扣 C_struct 的头部增益（同域）：保留率 30.2%（pk8）/ 62.1%（crt）——
   头窗在场但不可辨识时，其袋内增益仅剩同域可辨识时的 30.2%/62.1%；且袋平均本身已把
   头部增益从 1 窗域的 0.16/0.24 摊薄到 0.07/0.14，乱序再进一步压到 0.02/0.09。
3. 乱序场景下信道存活排序：**C_len（对象级，顺序无关）> C_bytes（无序袋）>
   C_align（需首尾块可观测）> C_struct（头部增益被摊薄+乱序双重折扣）**。
4. 1-NN 下三配置排序 B0<B1<B2 不变（敏感性检查通过）；rf100 与 rf300 方向一致。
